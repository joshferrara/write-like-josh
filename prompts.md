# Original Prompts

## Email Analysis

```text
/goal Use the gog cli to accomplish this task. Review the past 1 year of sent email on by personal and work email, analyze it for my unique tone and style of writing, and create markdown file that represents the way I write and could serve as detailed instructions for a person or agent attempting to write on my behalf. Ignore forwarded emails and anything that is obviously just transactional. Focus on actually writing, tone, prose, humor, length, technical nature, and any other helpful details that come across in your analysis.
```

## iMessage Analysis

```text
/goal use the imsg cli to do the same analysis on my sent iMessages on my Mac to see if there is any additional insights you can gain about my writing style. If there are new learnings, add them to the style guide
```
