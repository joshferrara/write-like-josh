# Write Like Josh

This repo contains a practical writing style guide for drafting in Josh Ferrara's voice.

## Files

- `write-like-josh.md` - the main style guide, based on analysis of Josh's personal/work email, sent iMessages, and sent Slack messages.
- `prompts.md` - the original prompts used to create and refine the guide.

## Use

Give `write-like-josh.md` to a person or agent before asking them to draft emails, texts, client updates, or other writing on Josh's behalf.
